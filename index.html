How this is builtMethodology

Every event is dated and sourced. Dates use the most precise resolution the source supports (YYYY-MM-DD > YYYY-MM > YYYY). Undisclosed is a first-class value, not a gap.

Confidence: HIGH = confirmed date + independently reviewable source; MEDIUM = named source, date approximate; LOW = single source, unverified.

Source types: company-claim, news, permit, filing, epoch-satellite, undisclosed. GPU install counts are not publicly observable at most sites and are not claimed unless a named source discloses them.

Entries are reviewed before publication; claims that cannot be independently corroborated are not included.

Read before you citeLimitations

This ledger tracks a curated working set of publicly reported sites selected for verifiable, linkable sourcing — it is not a complete census of the industry. Coverage skews toward sites with named, checkable sources; announced projects that never generated reviewable public reporting are not represented. Aggregate figures (capex, MW) reflect only the sites and disclosures listed here, not the full US buildout.
